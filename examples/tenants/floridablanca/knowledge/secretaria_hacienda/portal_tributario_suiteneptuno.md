# Portal Tributario - SuiteNeptuno (Alcaldía de Floridablanca)

La Alcaldía de Floridablanca gestiona sus trámites tributarios a través del portal **SuiteNeptuno**, distinto al sistema (CS3/SWIT) usado en otros despliegues de este asistente. **No existe una API pública ni script de consulta automatizada conocido para SuiteNeptuno**; toda gestión debe remitirse directamente al portal.
